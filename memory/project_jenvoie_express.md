J'Envoie Express est un partenaire stratégique de l'agence Attractor, pas un client ordinaire. L'app sert de DMV (Démonstration de Valeur) vivante pour vendre des apps métiers à d'autres clients.

**Gérant :** Jean Yves Gbouablé

**Deal financier :**
- Forfait spécial partenaire : 230€ total
- Acompte : 130€ (à encaisser pour démarrer)
- Solde : 100€ (à la livraison)
- Maintenance : 50€/mois

**Contrepartie :** Jean Yves fournit un témoignage (vidéo ou écrit) exploitable dans les démos et supports commerciaux de l'agence.

**Produit livré :**
- Dashboard admin back-office (ce que Jean Yves pilote au quotidien)
- Page publique clients (suivi colis, formulaire demande, tarifs)
- Domaine : jenvoieexpress.com (pris en charge par Attractor)
- Stack : Supabase + Netlify + n8n WhatsApp

**Maquette (DMV statique) :** `livrables/clients/demo-site/public/jenvoie-express/index.html`
**Architecture réutilisable :** `livrables/recherche-et-developpement/architecture-app-metier.md`

**Why:** Premier client app métier, utilisé pour prouver la valeur du concept avant de vendre aux tarifs standards (490–1290€). Le témoignage alimente le closing pour les prospects suivants.

**How to apply:** Quand Mac Arthur parle de J'Envoie Express, c'est une DMV partenaire. Toujours distinguer du pipeline client normal. Le témoignage est à recueillir dès la livraison.
