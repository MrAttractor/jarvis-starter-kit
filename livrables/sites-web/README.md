# Sites Web

Projets de sites internet pour clients, prospects ou marques.

Inclut : landing pages, sites corporate, vitrines, microsites.

## Organisation

```
sites-web/
├── [client]_[type-site]_v[version]/
│   ├── src/
│   ├── public/
│   ├── package.json
│   └── README.md
```

Exemples :
- `attractor-assists_landing_v1/`
- `chatflow_corporate_v2/`
- `client-xyz_ecommerce_v1/`
