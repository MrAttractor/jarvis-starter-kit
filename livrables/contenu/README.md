# Contenu

Campagne de création de contenu (logique AARRR : acquisition, activation, rétention, referral, revenue).

Ce qui y va :

- `manuel/` — le manuel d'acquisition (aide la cible à comprendre qu'elle doit rédiger ses procédures).
- `challenge-7-jours/` — le challenge gratuit de 7 jours.
- `scripts/` — scripts et hooks (posts, vidéos, séquences).
- `calendrier-editorial/` — planning de publication.

Convention : fichiers datés en `AAAA-MM-JJ-titre.md`.
