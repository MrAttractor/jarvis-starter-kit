# Applications

Outils, scripts, automatisations, apps métier.

Inclut : CLI, bots, automation scripts, web apps internes, backend services.

## Organisation

```
applications/
├── [app-name]_v[version]/
│   ├── src/
│   ├── package.json
│   ├── README.md
│   └── ...
```

Exemples :
- `livraison-pro_v1/`
- `fidelys_v2/`
- `automation-macros_v1/`
