## Règle de production

**On ne produit aucun contenu sans avoir analysé et validé les tendances de la cible.**

Séquence obligatoire :
```
Veille CI validée
    ↓
Ton + langage + tendances intégrés
    ↓
VOIX produit les textes finaux
    ↓
Canva produit les visuels adaptés
    ↓
Publication
```
