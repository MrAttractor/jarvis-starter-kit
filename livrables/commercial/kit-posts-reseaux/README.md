# Kit posts réseaux — Mr Attractor (FB + IG)

Générateur de visuels de posts sur la charte du site (Sora + Space Mono, orange #F25C05 / charbon / sable). Tu remplis, tu télécharges le PNG, tu programmes dans Meta Business Suite. Zéro Canva, zéro dépendance à quelqu'un.

## Comment l'utiliser

1. Ouvre **`generateur.html`** dans ton navigateur (double-clic).
2. Choisis le **format** (Feed 4:5 / Carré 1:1 / Story 9:16), le **thème** (Sombre / Clair), le **modèle** (Accroche / Offre / Preuve).
3. Remplis le texte. Le champ "Mot(s) en orange" met en accent une partie du titre.
4. Charge ton **image de fond** (astuce : sujet à droite, espace à gauche pour le texte). Sans image, un dégradé de marque est utilisé.
5. Clique **Télécharger le PNG**.
6. Va dans **Meta Business Suite → Planificateur**, ajoute le PNG, écris la légende, programme. FB + IG en une fois.

## Les 3 modèles

- **Accroche** : une idée forte (titre énorme + sous-titre). Pour capter.
- **Offre** : un service avec prix + points inclus + bouton. Pour vendre.
- **Preuve** : une citation / un résultat client. Pour rassurer.

## Presets par URL (bonus)

Tu peux ouvrir directement une config : `generateur.html?format=story&theme=clair&model=offre`.

## Notes

- Les images de fond peuvent venir de tes photos, de Magnific (IA), ou d'autres illustrations. `fond-01.jpg` est un exemple généré.
- Le PNG sort en pleine résolution (1080 px de large). Le téléchargement utilise html2canvas (nécessite une connexion internet la première fois pour charger la librairie et les polices).
- `exemple-01-methode.png` = un rendu de démonstration.
