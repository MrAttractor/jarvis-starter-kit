# Clients

Web apps métiers sur mesure livrées aux clients. **Un sous-dossier par client.**

Structure recommandée par client :

```
clients/
└── nom-client/
    ├── maquette/   # maquette de vente / démo (issue de maquette-closer)
    ├── app/        # l'application livrée
    └── docs/       # audit, cahier des charges, notes
```

Convention : nom de dossier en kebab-case sans accents (ex : `my-nugo`, `jenvoie-express`, `olive-mafo`).
