5. AGENT FRAMEWORK
Agent Core Loop

Chaque agent fonctionne comme ceci :

on_event(event):

  context = fetch_user_context(event.user_id)

  insights = analyze(event + context + memory)

  if opportunity_detected:
      action = generate_action(insights)

      log(action)

      emit(action_event)
Proactive mode (clé stratégique)

Chaque agent peut aussi fonctionner sans event :

proactive_scan:
  frequency: "every_2h"
  scope: "all_active_users"
Exemple AWA (Marketing)
détecte absence de contenu
propose posts
génère scripts vidéo
déclenche production IA
Exemple SERGE (Sales)
détecte leads non relancés
propose messages WhatsApp
génère relances automatiques
