# Design System References - Écosystème ATTRACTOR

Collecte structurée des créations et inspirations pour bâtir une identité visuelle cohérente sur l'écosystème ATTRACTOR.

## Structure

- **screenshots/** — Captures d'écran annotées des références
- **analyses/** — Fiches détaillées par référence (une par lien/source)
- **syntheses/** — Patterns identifiés et comparaisons transversales

## Workflow

### 1. Ajouter une référence

Crée un fichier `analyses/REF-[nom-court].md` :
```
# [Nom du produit/site]

**Source:** [lien]
**Date:** YYYY-MM-DD
**Type:** [UI app / Site web / Branding / Motion / Design system]
**Écosystème correspondant:** [Attractor Assists / Livraison Pro / Fidelys / Web app métier / ...]

## Ce qui m'inspire

- Point 1
- Point 2

## Éléments clés

### Couleurs
- Primaire: #XXXXXX (utilisation)
- Secondaire: #XXXXXX

### Typographie
- Headlines: [Police] [Taille/Poids]
- Body: [Police] [Taille/Poids]

### Layout / Spacing
- Description du système utilisé

### Composants notables
- Boutons, cartes, modales, etc.

## Notes techniques
```

### 2. Sauvegarder les captures
- Enregistre dans `screenshots/` avec le même code `REF-[nom]`
- Format: PNG ou WebP

### 3. Synthétiser les patterns
- Mise à jour régulière des fichiers `syntheses/` pour identifier les tendances
- Comparaison entre tes produits et les références

## Fichiers clés

- **PATTERNS.md** — Patterns visuels identifiés (à créer au fur et à mesure)
- **COMPARISON.md** — Matrice de comparaison entre produits
