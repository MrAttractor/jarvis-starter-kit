📘 BRIEF PRODUIT – ASSISTS (VERSION DEV SENIOR)
1. VISION GLOBALE

ASSISTS est une plateforme SaaS qui permet à un entrepreneur de créer en quelques minutes :

un site web public + un assistant IA + un CRM léger intégré

Mais derrière cette simplicité apparente, le système est une agence digitale autonome composée d’agents IA spécialisés.

2. POSITIONNEMENT PRODUIT

ASSISTS n’est pas :

un chatbot
un site builder
un CRM

ASSISTS est :

une infrastructure de présence digitale intelligente pour entrepreneurs, automatisée par IA.

3. ARCHITECTURE GLOBALE
3.1 Acteurs du système
1. Prospect / Client final
crée son espace ASSISTS
possède son site + assistant
vend ses produits/services
2. Carelle (Agent d’onboarding central)

Carelle est le point d’entrée humain simulé par IA.

Rôle :

accueillir le client
qualifier le besoin
collecter les données business
guider étape par étape
construire le site
préparer la base CRM
transmettre à l’assistant bras droit

Carelle est aussi :

superviseur des autres agents
orchestratrice du flux interne
3. Assistant “Bras Droit” (agent opérationnel client)

Une fois le site créé :

prend le relais client
gère les conversations business
répond aux prospects finaux
exécute les actions CRM légères
4. Back-office ASSISTS (plateforme interne)
dashboard admin
gestion des tenants
monitoring
gestion des agents
upsells
